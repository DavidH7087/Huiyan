# 慧眼 Phase 6E · 异常 PDF 文字层检测与 OCR 回退

针对 PDF 内嵌字体缺失映射，出现 `(cid:123)`、Unicode 私用区字符、方框占位符或大量 Unicode 替换字符的情况，解析器现在不会因为字符串长度正常就误判为有效文字。对于明显损坏的文字层，OCR 就绪时逐页回退到本机 Tesseract；若 OCR 未安装或扫描结果仍是乱码，该页标为不可读取，整份文件只有乱码时会返回可解释的导入失败，不会让伪文字参与候选人筛选。

本阶段仍保留正常文字 PDF 的原始文字层，避免对可复制的 PDF 误用 OCR；所有 OCR 结果仍标记为待人工核实。自动测试覆盖正常中文、字体私用区、CID 编码、丢字方框、替换字符、OCR 失败及没有 OCR 时的拒绝行为。对真实复杂 PDF 排版仍需用脱敏样本验收；该启发式不能保证检测所有字体乱码。
