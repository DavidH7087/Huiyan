# 慧眼 Phase 7D · 多轮筛选的语义向量复用

- SemanticMatcher 在内存中维护最多 4096 个文本向量的 LRU 缓存，供当前招聘任务及同一进程中的多轮筛选复用。相同候选人段落、相同关键词不重复调用 FastEmbed 或其他本地编码器。
- 使用线程锁保证并发请求中缓存及 CPU 模型推理的完整性；新文本仍按一个批次编码。
- 缓存仅存在于内存，关闭程序即释放；不上传简历、不新增持久化候选人副本。
- 通过自动测试验证重复筛选不重新编码、变更条件只计算新增文本、缓存上限被遵守。

**注意：** 首轮筛选与长扫描件 OCR 仍可能耗时；本次主要优化重复筛选。还没有完成千份简历持续负载测试，也不意味着真正语义召回率已达到生产标准。
