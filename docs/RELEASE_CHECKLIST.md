# 慧眼 · 预览版发布验收清单

**当前定位：可测试的 Windows 预览软件，非正式商用版。**

## 已由 GitHub CI 覆盖

- Python API、筛选结果、历史审核、导入、OCR 测试和前端脚本语法。
- Windows 环境打包为 EXE 并启动本机 HTTP 服务。
- Inno Setup 安装器的静默安装和安装后 EXE 冒烟测试（以 CI 实际结果为准）。

## 正式发布前必须补齐

- 在 Windows 11 用户桌面人工打开 WebView2 窗口，验证中文界面和真实交互。
- 大批量脱敏 PDF/DOCX/扫描件准确率、性能和意外关闭恢复测试；真实 OCR 和 BGE 推理质量验证。
- 真实企业资料的保护方案（访问控制、加密、保留期限、合法性依据、员工权限、清理和备份）。
- Windows 应用代码签名/病毒误报排查、安装/卸载测试、软件许可与第三方模型许可审查。
- 招聘公平性与人工最终审核制度；不得根据推测的敏感特征筛选候选人。
- 产品名称“慧眼”商标及商业使用风险核验。

**GitHub 公开仓库和 Codespaces 中绝对不要上传真实应聘者简历。**
