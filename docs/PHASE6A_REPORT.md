# 慧眼 Phase 6A · Windows 本地可视化加密备份恢复

本阶段新增完全本地、无需命令行的恢复功能：Windows HR 在「招聘档案」上传 `.hyb` 加密备份、输入正确密码并确认“恢复”，程序验证 AES-GCM、内部文件校验、SQLite 完整性及所需数据表，将数据解密恢复到**新建的本地档案目录**。通过独立的原子配置指针在**下一次启动**时启用恢复档案；当前在用档案文件不被删除、替换或覆盖。恢复成功后可使用「切回最初的本地档案」按钮，并在下次启动生效。整个过程不需要访问云端。

安全限制：备份导入和切换接口只允许 Windows 桌面本地模式；云端 Codespaces 模式返回 403。前端需要人工输入“恢复”，服务端设置单文件体积上限并以分块方式落盘至临时文件。错误密码、损坏/不完整的备份或不满足慧眼数据库模式要求的内容必须回滚，不修改当前使用的数据。恢复档案和旧档案会共存，占用额外磁盘空间，使用者需自行管理空间；密码丢失无法解密。恢复临时文件可能出现未加密的临时解密数据，应配合 BitLocker 和系统账户访问控制。

**测试范围：** 单元和 HTTP API 测试涵盖正确恢复、文件未被覆盖、恢复数据可重新打开、错误密码拒绝、非法或不完整档案拒绝、Codespaces 拒绝和配置路径安全。Windows GitHub Actions 保留安装后 EXE 启动检查。

**仍未验证：** 在真实 Windows 11 交互桌面上完整操作恢复、大容量真实企业数据库恢复和权限隔离。需要在测试电脑上使用虚构简历进行人工验收。不得将该预览版视为商业合规完成。
