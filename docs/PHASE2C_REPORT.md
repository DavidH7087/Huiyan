# 慧眼 · Phase 2C 开发记录

## 交付

- 新增保守的本地结构化简历提取器 `backend/profile.py`，只识别明确提及的学历、有限技术技能、文字工作年限、经历原文；每项记录原页与 OCR 来源。
- `resume_profiles` SQLite 表保存版本化档案；原先已导入的简历可在查看时自动补全档案，不修改原始简历及历史筛选快照。
- API `GET /api/tasks/{task_id}/resumes/{resume_id}/profile` 与候选人详情增加档案；前端阅读页显示结果和风险提醒。
- 新增单元/API 测试，包含同音误识别风险、Java 与 JavaScript 区分、不同年限冲突、跨任务权限验证。

## 局限

这不是 SmartResume 或 LLM 结构化模型，不做跨行业通用的完整经历归一化；绝不自动判断资质真实、计算连续工龄或给候选人打就业能力分数。实际简历分布和准确率仍需脱敏样本验证。
