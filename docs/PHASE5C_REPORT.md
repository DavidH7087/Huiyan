# 慧眼 Phase 5C · 加密招聘档案备份（预览）

## 新增

- Windows 桌面版在「招聘档案」页创建密码保护的完整备份（包括 SQLite 中的筛选历史、审核记录、候选人档案，以及原始上传简历）。导出 `.hyb` 文件供用户自行放在安全位置。
- AES-256-GCM 完整性保护，PBKDF2-HMAC-SHA256（48 万次迭代、随机盐）从用户密码派生密钥。**不保存密码**；错误密码或篡改文件不能恢复。
- 在后台使用 SQLite 在线快照备份一致的数据库，按流加密 ZIP；每个原文件有 SHA-256 校验。
- 提供 `python -m backend.backup restore <backup.hyb> <new_data_folder>` 恢复工具，**必须恢复到不存在的新目录**，不会覆盖正在使用的招聘数据库。恢复完成后需停掉慧眼，由具备权限的人员核对新目录并切换数据目录。暂不提供 HR 一键恢复向导。
- 限制文件数、原始文件大小、归档路径、解压总量。单次备份上限 1GB/5000 个文件，以防资源耗尽。

## 重要限制

- 备份内容可能包含大量个人信息。密码应至少 12 字符并离线保存，妥善保管备份。**丢失密码无法恢复**。
- SQLite 快照写入临时明文文件，恢复时也会暂时生成明文归档，应在启用 BitLocker 等全盘加密的受控电脑上操作。程序会清理正常过程的临时文件，但无法保证强制断电后的磁盘安全擦除。
- 当前未实现定时自动备份、云同步、多人权限管理、图形化一键还原、企业密钥管理。桌面本地请求防护不是完整的登录认证体系。
- 备份和恢复流程通过虚构数据做端到端回归，实际企业规模的恢复演练仍需完成。

## 使用

桌面版进入「招聘档案」，输入 12 字符以上的密码后点击创建加密备份，下载到用户选择的位置。

在停止应用的恢复环境中（需要 Python 环境和项目依赖）：

```bash
python -m backend.backup restore backup.hyb restored-data
```

按提示输入备份密码，再检查 `restored-data` 内容。恢复目标必须是全新的不存在目录。**不要直接覆盖正在运行的 `%LOCALAPPDATA%\\Huiyan\\data`。**
