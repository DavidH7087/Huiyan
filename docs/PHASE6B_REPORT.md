# 慧眼 Phase 6B · 排除线索及精确/同义关键词筛选

新增岗位「排除线索」和「关键词匹配模式」两项可选配置。默认使用现有同义词扩展；切换到“精确文字”时不进行同义词扩展。排除线索仅根据原文匹配生成需要 HR 核实的提醒，不自动淘汰、不隐藏、不删除候选人，OCR 证据标记需核对。明显的文字否定、课程/求职意向不会作为正面排除依据（局限于既有保守语境规则，仍会有误差）。

数据库在软件启动时自动安全迁移旧 `tasks` 表，给新增字段设置默认值，不覆盖历史数据。每轮保存 `excluded` 与 `match_mode` 的完整快照，后续调整不会更改已有结果。Excel 导出新增「需核对排除线索」及「文字匹配方式」两列；候选人详情突出显示需核实线索。

自动测试覆盖精确模式、同义词模式、否定描述、OCR、API 端到端、历史快照不可变、Excel 导出及旧版数据库迁移。该功能属于可解释文字检索，不验证应聘者是否满足真实资格；不得将敏感个人特征用于招聘差别待遇，任何排除线索均需人工复核。真实企业招聘的准确率及公平性仍需独立验收。
