# 慧眼 Phase 6F · 中文/英文轻量 BM25 辅助排序

引入不依赖外部模型、不联网的 BM25 词法相关性辅助层。对中文简历计算有限字符二元/三元词组，对 Java、SQL、Python 等英文术语保留完整词；计算查询来自岗位描述、必选、加分及本轮补充条件。单份简历最多取 3000 个 token，避免超大文档产生无限计算；每轮内部返回 0 至 1 的相对文本相关性，**不跨任务对比，也不等于候选人能力得分**。

只有在完成必要条件和排除线索检查后，此分数才以最大 0.3 的有限幅度调整同组展示顺序，不改变“优先查看／需要确认”的分组，不删除候选人。每轮 `criteria_json` 记录 `bm25_lexical_v1`，每名候选人的结果保留文本相关性字段供技术审核；普通 HR 界面隐藏算法权重，以原始证据和人工审核为主。

测试验证中英文词法、相关/不相关文档排序、空查询、长度上限及与必要条件判断独立。该功能不具备深度语义推理；可选本地向量模型是另一项功能，尚需真实模型效果和资源消耗验收。
