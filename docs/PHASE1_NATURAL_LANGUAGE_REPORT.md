# 慧眼 · 阶段一（首批）自然语言与混合筛选

## 已提交到独立开发分支
- 岗位描述可以在无手工关键词时用于创建任务和筛选。
- 描述提取为最多 8 条文字线索，与用户自己填写的必须/优先/排除条件并用。
- 描述线索在数据库的每轮筛选快照里单独记录；不会自动写入“必须具备”，不自动删除候选人。
- 复杂补充筛选不再把整段文字直接作为精确关键词，而是提取有限线索。
- 更新面向普通 HR 的 UI 文案，并增加描述-only、混合、否定要求与历史线索追溯的测试。

## 仍然存在的限制
当前提取器是保守的规则式短语提取，不是完整中文语义理解。
对描述的短语切分可能产生多余线索，须在接下来的阶段用独立标注测试集验证召回率和误判情况。
当前所有匹配都只能解释为原文相关线索，不是资格认证。
下一步还应允许 HR 在确认页直接编辑自动提取的描述线索，并针对复杂长句增强拆分。
