# 慧眼 v0.9.4-preview · 资历核对与原文定位质量报告

## 范围

继续改进 HR 简历审核体验，不增加不透明的自动评分或自动淘汰。

### 筛选证据与原文衔接

每项有直接文字证据、否定表述或语义线索的条件均可点击“查看原文”。软件打开已提取的本地简历文本，展开相应页码，并在实际原文包含证据文字时标出对应句子。如果换行或格式导致文字无法精确匹配，仍会展示该页，不编造高亮。不会重新开放已按用户要求移除的 `/original` 文件接口。

### 年限和正向资历

结构化摘要升级为 `rules-v3`。只有不同陈述中的总工作年限互相矛盾时，才标记总年限冲突。不同技能或岗位的具体经历年限不会自动被当作总工龄冲突。每一条年限提取保留原文和页码。

“未取得本科学历”“不熟悉 Python”“岗位要求至少 5 年工作经验”等否定和要求描述不应展示为已拥有的正向资历。支持“5年以上的工作经验”等写法，并区分“没有 Python，但熟悉 Excel”中的两段信息。

### 240 份合成简历批量验证

原专项测试仍请求已移除的原文件 HTTP 接口，导致此前主分支的 Synthetic Corpus 任务失败。此轮修复测试脚本，改为直接读取隔离的本地上传目录、验证 SHA256 与数据库内容哈希一致，同时保留 120 DOCX + 120 文字型 PDF 的导入与结果数量测试。

## 兼容性

- 更新简历详情时只重算结构化摘要缓存；不修改原始简历、用户姓名、条件、筛选历史、人工审核或备注。
- 界面显示依据仅供 HR 复核，不等同实际教育背景、能力或经历已经核实。
- 未对真实企业简历的质量、公平性、合规性或 Windows 可见窗口自动判定通过。
- GitHub CI、Chromium、Windows 两种安装包、OCR 和专门的合成数据测试均需要绿色验证后才合并。
