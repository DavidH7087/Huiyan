# 慧眼 Phase 6C · 桌面本地进程会话保护

Windows 打包程序启动后会生成一次性、不可预测的 32 字节随机会话密钥。只有带有正确启动令牌的内置 WebView2 窗口才能经一次性 URL 跳转换取 `HttpOnly`、`SameSite=Strict` 的本地会话 Cookie；之后所有简历、招聘任务、备份、筛选和静态页面接口均需 Cookie 验证。其他本地浏览器、未经授权的网站或未提供令牌的请求无法直接枚举简历。为了应用启动与 Windows CI 冒烟测试，低敏的 `/api/health` 保留无需 Cookie 的本机只读访问。

此会话层与先前的 Host / Origin 检查叠加，并仅在 Windows 桌面模式且已生成真实启动令牌时启用。Codespaces 网页预览仍使用原有开发模式；如需在互联网上部署慧眼，必须重新设计正式身份认证、HTTPS、多租户权限等机制，**不能复用此本机会话作为云端登录系统**。

限制：同一 Windows 账户下能够读取进程环境、注入代码或操作 WebView2 的恶意软件仍可能访问数据；本措施不替代磁盘加密、操作系统账户权限和企业安全审查。安全回归测试覆盖无 Cookie 拒绝、错误令牌拒绝、正确引导后通过、跨站 Origin 拒绝、不同浏览器会话隔离及 Codespaces 普通预览。
