# 慧眼 v0.1 第一阶段实施记录

## 已实现

- 简洁中文首页及招聘任务、招聘档案导航。
- 录入自然语言招聘描述，基于有限领域术语生成可编辑的必要与优先条件草稿。
- 创建和归档招聘任务；SQLite 本地保存任务数据。
- 支持 PDF、DOCX、TXT、ZIP 文件上传，文件大小限制、ZIP 路径检查、内容哈希去重、解析异常记录。
- 条件相关文字及同义词检索，返回对应原文及页码、需要核实的条目。
- 筛选结果列表、条件查看、原简历下载、人工审核与备注。
- 多轮筛选与父轮次引用、历史快照存储、Excel 导出。
- Codespaces 开发配置与启动脚本。

## 不属于当前版本

- 尚无 SmartResume/PaddleOCR、BGE、Reranker、Qwen 的真正运行与效果测评。
- 目前自然语言条件理解仅支持小型词典；不适合声称可准确理解所有岗位要求。
- 没有 Windows 原生安装程序，也没有针对公司实际硬件的离线实测。
- 没有完整用户身份权限、加密、数据保留期限机制、数据库备份恢复。
- 批量解析目前是一次请求内执行，尚无可恢复后台队列、暂停/恢复和精细任务进度。

## 安全边界

- GitHub 仓库只保存源码，不提交真实简历或个人资料。
- Codespaces 是托管云开发环境，不应视作满足企业本地离线数据策略。
- 自动排序仅作为文字证据检索辅助；最终招聘判断始终由 HR 完成。
