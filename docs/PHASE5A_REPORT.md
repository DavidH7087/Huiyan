# 慧眼 Phase 5A · 语境误匹配修复

## 范围

调整本地证据检索：不再把求职意向、简历测试声明、课程/培训词汇、明确否定、未说明是否承担的岗位职责当成已证实的工作经历。保留原先的逐项证据页码和人工审核流程。此修复只改变文字检索，未使用外部 API 或预训练 AI 模型。

## 验证

使用先前固定的 **120 份完全虚构简历和人工预置标签**做回归。旧版报告的 22 条错误优先查看是这次回归的基线。本阶段在开发测试环境中，对经过保守语境规则修订的检索逻辑重新运行相同数据，结果为 60 条优先查看、60 条需要确认，对应预设标签；GitHub CI 加入逐份核对测试，防止同类回归。同时增加负面、课程和真实经历并存的独立单元测试。

这 **不代表真实招聘的准确率为 100%**：测试集是模板合成且容易过拟合。中文表达复杂、OCR 误识别、跨句事实冲突、能力造假等仍需人工核对。不得根据标签自动淘汰候选人。

## 后续

扩展来自不同排版/行业的匿名授权样本，避免仅对当前合成词句调优；评测真正的本地语义模型并实现更可靠的可解释判断。
