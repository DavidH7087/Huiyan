# 慧眼 Phase 5E · 跨格式疑似重复候选人提示

**目标**：同一候选人上传不同 Word/PDF 版本时，文件哈希不同，不会被现有内容去重逻辑识别。新增低风险的候选人联系方式相同提示。

- 在招聘任务内，按**完全相同的电子邮箱（忽略大小写）**或**有效的 11 位中国大陆手机号（忽略空格和分隔符）**检测疑似重复简历。
- 候选人列表和详情页展示「疑似重复」标识、可能重复的其他简历 ID，以及匹配依据。
- `GET /api/tasks/{id}/duplicates` 提供同任务的疑似重复分组，以便后续工作流引用。
- **不会基于姓名自动合并**：同名很常见。不会删除任何原始文件、合并人工审核、跳过筛选，避免误伤不同候选人。
- 已补充纯函数测试与 API 端到端测试：邮箱大小写、手机号格式、无效占位电话、多份简历和不同任务隔离。

## 仍需改善

- 同一候选人不同简历可能没有相同联系方式，无法自动匹配。
- 共用邮箱和共用工作号码可能误触发提示；因此必须由 HR 人工判断。
- 多格式归档可提供手动确认合并与保留全部版本的版本管理，后续迭代再实现。
