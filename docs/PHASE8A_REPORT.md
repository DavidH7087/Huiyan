# 慧眼 Phase 8A · 个人简历删除与数据生命周期

已提供针对单一候选人的永久删除能力。HR 需要输入完整的原文件名确认；删除对应的原文件、个人档案缓存、筛选证据、审核及导入记录，保留同一招聘任务中的其他候选人。由于隐私删除优先于历史快照，删除后各轮次候选人数量会相应变化。

数据库保留不含候选人身份的删除事件记录。文件清理失败时会返回明确警告，而不是宣称已清理成功。已另行导出到外部的加密备份和其他副本无法由软件自动撤回，需按公司留存政策管理。本功能不保证固态硬盘上的物理安全擦除。

回归测试涵盖确认校验、原文件清理、跨轮次级联删除、保留其他候选人、旧链接失效及审核日志移除。正式企业使用仍需访问权限、数据保留期限和法规审查。
