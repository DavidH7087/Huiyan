# 慧眼 Phase 7B · 轻量中文本地语义检索

## 实现内容

- 支持可选 `BAAI/bge-small-zh-v1.5` CPU ONNX 模型适配器；与已有 SemanticMatcher 共用相似段落检索与证据来源结构。
- 明确分离 `prepare` 的一次性公开模型权重下载，与 `local_files_only=True` 的实际招聘筛选；不上传简历，不自动联网下载模型。
- 缺少模型时自动回退原有的关键词+BM25 基础引擎；状态透明，不伪装 AI 已启用。
- 保留既有本地 SentenceTransformers BGE-M3 模型适配层；模型有明确配置目录时优先采用。
- 增加单元测试（加载/回退/离线协议）及专用真实模型 CI。真实模型 CI 只处理虚构的测试句子。

## 未完成/发布约束

- 当前普通 Windows 安装包**尚未捆绑** FastEmbed 依赖与模型，因此用户需要额外安装配置才能使用。
- 尚未做跨行业真实招聘质量、离线断网长时压力测试。真实模型能生成相似段落，不等同于录用资格或工作能力证明。
- 商业发行需复核 FastEmbed、ONNX Runtime 以及模型和二进制第三方许可、中文语义召回偏差。
